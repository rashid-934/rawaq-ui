# Rawaq UI

Rawaq UI (رواق) is one theme for React and Mantine apps: design tokens, an app shell and motion.
The layout style inside it is called "Rail and Bento": a dark floating icon rail, a soft haze
background and the app inside one rounded frame.

Status: version 1.0.0 is being built on the branch `feat/v1`. This page becomes the full guide
("Start a new app with Rawaq UI") with that release. Progress is in `PROGRESS.md` on that branch.
